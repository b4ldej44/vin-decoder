# VIN-декодер

Бесплатная расшифровка VIN для BMW, Mercedes-Benz и Audi. Работает целиком в
браузере: без сервера, без регистрации и без платных API.

## Что умеет

- **Из VIN:** производитель и страна, серия (Mercedes) или модель (Audi),
  модельный год, завод, серийный номер, контрольная цифра. Подсказывает, если
  VIN введён с ошибкой.
- **Справочник NHTSA:** двигатель, кузов, привод и прочее. Хорошо знает машины
  рынка США, о европейских почти ничего.
- **Комплектация по кодам опций:** SA-коды BMW, коды Mercedes, PR-коды Audi.
  Коды вставляются вручную или целым текстом отчёта.

Полный список опций только по VIN бесплатно получить нельзя: он хранится в
базах производителей, доступ к которым платный.

## Общая база комплектаций

Кто-то сохранил коды опций для VIN — следующий, кто введёт этот VIN, видит
комплектацию сразу и сколько человек её подтвердили. Регистрация не нужна.

Хранится в Supabase (бесплатный тариф). Включить один раз: в проекте Supabase
**SQL Editor → New query**, вставить `supabase.sql` → **Run**. Адрес проекта
и публичный ключ — в `config.js`. Без этого шага блок показывает «Общая база
сейчас недоступна», остальное работает.

## Где взять коды опций

- **Audi** — наклейка в нише запасного колеса и сервисная книжка.
- **Mercedes-Benz** — карта данных (Datenkarte), её распечатает любой дилер.
- **BMW** — выписка дилера или любой отчёт с SA-кодами.

## Как пополнить справочник

Все справочники — в `codes.js`. Добавьте строку `"КОД": "Описание"` в нужный
раздел. Неизвестные коды на странице показываются как «нет в справочнике».

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```sh
python3 -m http.server 8000
```

## Публикация

Репозиторий без сборки: в Vercel, Netlify или GitHub Pages достаточно указать
корень репозитория.
